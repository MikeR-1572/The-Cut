Host Tools

Terminate Game Cleanly

Force-ends the current hand from any phase. The pot is left untouched for later manual handling.

Restore Player Stacks

Resets every stack to the start of the current hand and clears the pot.

Remove Player

Forces the same outcome as if the player had clicked Leave Table themselves.

End Game

Ends the entire table/session -- everyone is disconnected and the table itself ceases to exist. Distinct from Terminate Cleanly, which only ends the current hand.
